# SOC Lab Notebook

A public log of my path from networking fundamentals to SOC and detection engineering.
One page per week: what I learned, what I built, what broke and how I fixed it.

## Stages

1. Foundations: networking, Linux, Windows (in progress)
2. SOC analyst and SC-200
3. Detection engineering
4. SOC engineering and automation
5. Expert track

## How this repo protects secrets

- gitleaks scans every commit before it's made and blocks it if it finds a secret (see `.pre-commit-config.yaml`).
- GitHub push protection is on.
- Every page passes a privacy check: no real IPs, hostnames, usernames, credentials, or school or employer data.
